# 生活，下一站见

一页独立制作的美团产品介绍。开场页用可随鼠标轻微倾斜的六张插画卡片概览外卖、到店消费、即时购物、酒店旅行、买药健康与出行服务；悬停可查看简介，点击可直达相应章节。后续内容依次介绍六项生活服务、四步使用方式、周末出游与结尾页底部的简洁常见问题。六个服务模块各有三张随滚动依次出现的原创图文卡片；周末出游集中在一个静态页面，四个步骤同时可见，可用鼠标预览并点击保留选择。页面及插画均为原创示意，非美团官方页面。

视觉采用浅美团黄、深绿色文字与浅薄荷色阅读区块，以平面色块和清晰边线组织内容。开场地图与服务卡片的鼠标跟随经过缓动处理；服务卡片的入场动画达到约 70% 时即可交互。周末出游采用浅蓝背景和静态的轻微倾斜卡片排布。每次进入模块时，画面空白处会出现一次较大、清晰的水蓝色波纹。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
pnpm install
pnpm dev
```

浏览器打开终端给出的本地地址。生产构建运行 `pnpm build`。

## 动效与性能

- [Three.js](https://github.com/mrdoob/three.js) 绘制低面数的微缩城市。
- [GSAP / ScrollTrigger](https://github.com/greensock/GSAP) 驱动滚动叙事、镜头与章节进度。
- 开始页和城市总览分别滚动至 50% 时切到下一模块；其余服务、使用方式与周末出游模块各自滚动至 70% 时缓动切到下一模块。结尾页合并常见问题，问答可点击展开。服务模块彼此之间的缓动切换更舒缓。页面内目录和卡片链接仍可直达对应内容。
- 每张服务卡片在上一张完成后才随滚动放大出现，三张错位叠放；悬停或聚焦时，当前卡片会摆正、置顶并跟随鼠标呈现局部光感。当前地标有轻微抬升与聚焦光环。
- 服务和周末卡片图片使用项目内生成的 SVG 插画，不依赖远程图片服务。
- 限制设备像素比为 1.5，复用材质，窗户使用实例化网格；流程与周末出游章节暂停 WebGL 渲染。
- 遵循系统的减少动态效果设置。卡片悬停、章节切换与点击有轻量音效；浏览器要求先点击页面或页眉的「开启音效」才能播放声音；自动切页会在切换开始时发声，页眉可静音，设置会保存在本地。

当前版本针对桌面浏览器设计。
